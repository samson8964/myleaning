# 从发现价差，到经营别人愿意长期付费的能力

跨行业长期商业模式研究报告，资料访问日：2026年11月2日。

本仓库是可直接部署到 GitHub Pages 的静态网页，无需安装依赖或构建。

## 文件

- `index.html`：完整网页阅读版，包含目录、来源链接和打印入口。
- `lifetime-business-research-2026-11-02.md`：可下载的 Markdown 原文。
- `.nojekyll`：使 GitHub Pages 直接发布静态文件。

## GitHub Pages 配置

在仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，再选择发布分支和 **/(root)** 目录。保存后使用 GitHub Pages 返回的实际访问地址。

正文、样式和机制图谱均包含在 `index.html` 内，页面阅读无需加载外部脚本、字体或样式。外部来源链接需联网访问。

报告区分真实商业案例、合理推导和待验证假设；企业提供某类服务，不代表新进入者必然盈利。
